## 🇰🇷 한국어 패치

최신 영문 언어파일 `lang_en.json`의  
**4,340개 항목을 기준으로 전체 대조·번역·검수**했습니다.

RSL Helper에는 공식 한국어 언어 슬롯이 없기 때문에  
**Français 언어 슬롯을 이용하여 한국어를 적용**합니다.

패치 적용 후 RSL Helper에서

**Language → Français**

를 선택하면 한국어로 표시됩니다.

## 📦 배포파일 구성

압축을 해제하면 다음 파일들이 포함되어 있습니다.

- `Jairodorp_RSL_Korean_Patch.exe`
- `lang_fr_KO_backup.json`
- `_internal` 폴더

⚠️ `_internal` 폴더와 `lang_fr_KO_backup.json` 파일을  
삭제하거나 다른 위치로 이동하지 마세요.

**압축을 해제한 폴더 전체를 그대로 유지하여 사용해 주세요.**
